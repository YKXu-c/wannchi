项目背景

hrJS/wannchi 项目基于 Wannier 哈密顿量计算磁化率和谱函数。本次新增 4 个 Fortran 模块：

模块 功能
modules/bayesian.f90 GP Bayesian 优化，拟合 J(R) 和 S 向量
modules/classical_mc.f90 经典 Heisenberg MC，计算热平均磁矩 m(T)
modules/ahc_calc.f90 反常霍尔电导率（Berry 曲率，无数值求导）
src/wanneff_JS.f90 主流程：下折叠→Bayesian 拟合→MC 温度扫描→输出 HR

关键设计决策

  • 构建：保留现有 Makefile（不用 fpm）
  • J-S 耦合：仅支持 spinor 模式
  • S 为 3 维向量 S = (S_x, S_y, S_z)，完整 J·(S·σ/2) 耦合矩阵
  • tsf = NN s-f 跃迁；tsf2 = on-site s-f（默认 0）
  • J_TENSOR=.false.（默认）：标量 J，Bayesian 参数 (J_0, S_x, S_y, S_z)，4 维
  • J_TENSOR=.true.：J(R) 张量，Bayesian 参数 (J(R_1),...,J(R_n), S_x, S_y, S_z)，(n_jrpt+3) 维
  • J_R_range(6)：(Rx_min,Rx_max,Ry_min,Ry_max,Rz_min,Rz_max)，全零则用 seedbare R-grid
  • tol_Jeff：Bayesian 收敛后对 J(R) 的剪枝阈值（非优化过程中）
  • mc_weiss_mean_field=.true.：自动推导 J_mc = J_eff × S_mag / z
  • 单测试文件：kagome_f_spinor_test.py

物理公式

下折叠（ω=0 静态极限） 

G_full(k, 0) = -H_seed(k)^{-1}              [已移位到 E_F=0]
G_CC(k)      = G_full(k)[CC 块]
H_eff_CC(k)  = -G_CC(k)^{-1}

[Ref: Kotliar et al., RMP 78, 865 (2006)]

J-S 交换耦合（Kondo 晶格） 

S·σ/2 = [[S_z/2,      (S_x-iS_y)/2],
          [(S_x+iS_y)/2, -S_z/2    ]]

标量模式: H_JS(k) = J_0 · (S·σ/2)
张量模式: H_JS(k) = (Σ_R J(R) e^{ik·R}) · (S·σ/2)

对每个 CC 轨道 io（spinor：1..n_c 为自旋↑，n_c+1..2n_c 为自旋↓）：

hr(io,     io,     R) += J(R)*S_z/2
hr(io+n_c, io+n_c, R) -= J(R)*S_z/2
hr(io,     io+n_c, R) += J(R)*(S_x-iS_y)/2
hr(io+n_c, io,     R) += J(R)*(S_x+iS_y)/2

[Ref: Coleman, Many-Body Physics (2015); Doniach, Physica B 91 (1977)]

反常霍尔电导率（AHC） 

σ_xy = -(e²/h) · (1/N_k) · Σ_k Σ_n f_n(k) · Ω_n(k)
Ω_n(k) = -2 Im Σ_{m≠n} <n|v_x|m><m|v_y|n> / (E_n-E_m)²

速度算符（解析式，无数值求导）：
v_α(io,jo) = Σ_R [i·2π·R̃_α · e^{i2πk·R}/w(R)] · conj(phase_io)·phase_jo·hr(io,jo,R)
R̃_α = R_α + τ_{jo,α} - τ_{io,α}

[Ref: Wang et al., PRB 74, 195118 (2006); Yao et al., PRL 92, 037204 (2004)]

Bayesian 优化（GP-EI） 

核函数: k(x,x') = σ_f² · exp(-||x-x'||²/(2l²)) + σ_n²·δ
预测:   μ(x*) = k(x*,X)·K^{-1}·y,   σ²(x*) = k(x*,x*) - k(x*,X)·K^{-1}·k(X,x*)
EI:     (y_best-μ)·Φ(z) + σ·φ(z),   z=(y_best-μ)/σ
高维搜索: 随机采样 N_cand = max(1000, 50*(n_jrpt+3)) 候选点

[Ref: Mockus (1989); Brochu et al. arXiv:1012.2599; Bergstra & Bengio, JMLR 13 (2012)]

经典 MC（Metropolis-Heisenberg） 

E = -J_mc · Σ_{<ij>} S_i·S_j,   |S_i| = S_mag
P_accept = min(1, exp(-ΔE/T))
Weiss MFT: J_mc = J_eff·S_mag/z,   T_c ≈ J_eff·S_mag²/3
输出: mvec_vs_T(3, n_temps),   S_eff_vec(T) = S_mag · mvec_vs_T(:,iT)

[Ref: Janke, Monte Carlo Simulations of Spin Systems, Springer (1996)]

Kagome 测试模型 

格子向量: a1=(1,0,0), a2=(0.5,√3/2,0), a3=(0,0,10) [2D]

位点（分数坐标）:
  1: (0,   0,   0) — s 轨道
  2: (0.5, 0,   0) — s 轨道
  3: (0,   0.5, 0) — s 轨道
  4: (0.5, 0.5, 0) — s+f 轨道

seed norb = 2×(4s+1f) = 10 (spinor)
seedbare norb = 2×4s = 8 (spinor)

跃迁: tss=-1.0 eV, tsf=-0.15 eV, tsf2=0.0 eV
R 截止: WS 构建，nr=5×5×1 → nrpt=31

轨道顺序 (seed):  [s1↑,s2↑,s3↑,s4↑,f4↑, s1↓,s2↓,s3↓,s4↓,f4↓]
轨道顺序 (bare):  [s1↑,s2↑,s3↑,s4↑, s1↓,s2↓,s3↓,s4↓]

能带路径: Γ(0,0,0) → M(0.5,0,0) → K(1/3,1/3,0) → Γ  (100点/段)

HR 构建注意事项（Python）：

  • s-f 跃迁需要分两个循环：前向 d(f_site, s_i+R) 和反向 d(s_i, f_site+R)
  • 均需 d > 1e-8 排除 on-site（同一位点距离为 0）
  • on-site f-s 耦合（tsf2）单独在 d<1e-8 时处理
